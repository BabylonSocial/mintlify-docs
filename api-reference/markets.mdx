# Markets API

Complete API reference for trading on prediction markets and perpetual futures.

## Base Endpoints

```
GET    /api/markets/predictions          # Get all prediction markets
POST   /api/markets/predictions/[id]/buy    # Buy shares
POST   /api/markets/predictions/[id]/sell   # Sell shares
GET    /api/markets/perps                 # Get perpetual futures markets
POST   /api/markets/perps/open            # Open perpetual position
POST   /api/markets/perps/[positionId]/close  # Close perpetual position
GET    /api/markets/positions/[userId]    # Get user positions
```

## Prediction Markets

### Get Prediction Markets

Get all active prediction markets.

```http
GET /api/markets/predictions
GET /api/markets/predictions?status=active
GET /api/markets/predictions?userId=user123  # Include user positions
```

**Query Parameters:**
- `status` - Filter by status: `active`, `resolved`, `closed`
- `userId` - Include user's positions if authenticated

**Response:**
```json
{
  "success": true,
  "markets": [
    {
      "id": "market-123",
      "question": "Will Bitcoin reach $100k by Q1 2026?",
      "yesPrice": 0.45,
      "noPrice": 0.55,
      "yesShares": 1000,
      "noShares": 1200,
      "volume": 50000,
      "status": "active",
      "resolvesAt": "2026-03-31T23:59:59Z",
      "userPosition": {
        "outcome": "YES",
        "shares": 50,
        "avgPrice": 0.42
      }
    }
  ]
}
```

### Buy Shares

Buy YES or NO shares in a prediction market.

```http
POST /api/markets/predictions/[id]/buy
Content-Type: application/json
Authorization: Bearer YOUR_TOKEN

{
  "outcome": "YES",
  "amount": 100
}
```

**Request Body:**
- `outcome` (required) - `"YES"` or `"NO"`
- `amount` (required) - Points to spend (number)

**Response:**
```json
{
  "success": true,
  "position": {
    "id": "pos-456",
    "marketId": "market-123",
    "outcome": "YES",
    "shares": 125.5,
    "avgPrice": 0.398,
    "totalCost": 100
  }
}
```

### Sell Shares

Sell shares from an existing position.

```http
POST /api/markets/predictions/[id]/sell
Content-Type: application/json
Authorization: Bearer YOUR_TOKEN

{
  "shares": 50
}
```

**Request Body:**
- `shares` (required) - Number of shares to sell (number)

**Response:**
```json
{
  "success": true,
  "sale": {
    "sharesSold": 50,
    "proceeds": 22.5,
    "remainingShares": 75.5
  }
}
```

## Perpetual Futures

### Get Perpetual Markets

Get all available perpetual futures markets.

```http
GET /api/markets/perps
```

**Response:**
```json
{
  "success": true,
  "markets": [
    {
      "ticker": "TECH",
      "name": "Tech Sector Index",
      "currentPrice": 1250.50,
      "24hChange": 2.5,
      "openInterest": 500000,
      "fundingRate": 0.0001
    }
  ]
}
```

### Open Position

Open a new perpetual futures position.

```http
POST /api/markets/perps/open
Content-Type: application/json
Authorization: Bearer YOUR_TOKEN

{
  "ticker": "TECH",
  "side": "long",
  "amount": 1000,
  "leverage": 10
}
```

**Request Body:**
- `ticker` (required) - Market ticker symbol (string)
- `side` (required) - `"long"` or `"short"`
- `amount` (required) - Position size in points (number)
- `leverage` (optional) - Leverage multiplier (default: 1, max: 20)

**Response:**
```json
{
  "success": true,
  "position": {
    "id": "pos-789",
    "ticker": "TECH",
    "side": "long",
    "size": 1000,
    "leverage": 10,
    "entryPrice": 1250.50,
    "liquidationPrice": 1125.45,
    "margin": 100
  }
}
```

### Close Position

Close an existing perpetual position.

```http
POST /api/markets/perps/[positionId]/close
Content-Type: application/json
Authorization: Bearer YOUR_TOKEN
```

**Response:**
```json
{
  "success": true,
  "close": {
    "positionId": "pos-789",
    "pnl": 125.50,
    "exitPrice": 1262.75,
    "fees": 2.50
  }
}
```

### Get Trades

Get recent trades across all markets.

```http
GET /api/trades?limit=50&offset=0
GET /api/trades?userId=user123
```

**Query Parameters:**
- `limit` - Number of trades to return (default: 50)
- `offset` - Pagination offset
- `userId` - Filter by user

**Response:**
```json
{
  "success": true,
  "trades": [
    {
      "id": "trade-123",
      "marketId": "market-123",
      "type": "prediction",
      "outcome": "YES",
      "shares": 50,
      "price": 0.45,
      "userId": "user-123",
      "timestamp": "2026-02-09T12:00:00Z"
    }
  ]
}
```

## Market Data

### Get Market History

Get historical price data for a prediction market.

```http
GET /api/markets/predictions/[id]/history
```

**Response:**
```json
{
  "success": true,
  "history": [
    {
      "timestamp": "2026-02-09T10:00:00Z",
      "yesPrice": 0.42,
      "noPrice": 0.58,
      "volume": 1000
    }
  ]
}
```

## Error Codes

| Code | Description |
|------|-------------|
| `INSUFFICIENT_BALANCE` | Not enough points to complete trade |
| `INVALID_MARKET` | Market ID not found |
| `MARKET_CLOSED` | Market is no longer accepting trades |
| `INVALID_OUTCOME` | Outcome must be "YES" or "NO" |
| `INVALID_AMOUNT` | Amount must be positive |
| `POSITION_NOT_FOUND` | Position ID not found |
| `LEVERAGE_TOO_HIGH` | Leverage exceeds maximum allowed |

## Rate Limits

- **Trading endpoints**: 30 requests per minute
- **Market data endpoints**: 100 requests per minute

## Examples

### Complete Trading Workflow

```typescript
// 1. Get markets
const markets = await fetch('/api/markets/predictions')
const { markets } = await markets.json()

// 2. Buy YES shares
const buyResponse = await fetch(`/api/markets/predictions/${markets[0].id}/buy`, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    outcome: 'YES',
    amount: 100
  })
})
const { position } = await buyResponse.json()

// 3. Check positions
const positions = await fetch(`/api/markets/positions/${userId}`, {
  headers: { 'Authorization': `Bearer ${token}` }
})
const { positions } = await positions.json()

// 4. Sell shares
await fetch(`/api/markets/predictions/${markets[0].id}/sell`, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    shares: 50
  })
})
```
