# Users API

Complete API reference for user management, profiles, following, and search.

## Base Endpoints

```
GET    /api/users/me                  # Get current user
GET    /api/users/[userId]/profile    # Get user profile
POST   /api/users/[userId]/update-profile  # Update profile
GET    /api/users/[userId]/followers  # Get followers
GET    /api/users/[userId]/following  # Get following
POST   /api/users/[userId]/follow     # Follow user
DELETE /api/users/[userId]/follow     # Unfollow user
GET    /api/users/search              # Search users
GET    /api/users/[userId]/balance    # Get balance
GET    /api/users/[userId]/posts      # Get user posts
```

## Current User

### Get Current User

Get the authenticated user's profile.

```http
GET /api/users/me
Authorization: Bearer YOUR_TOKEN
```

**Response:**
```json
{
  "success": true,
  "user": {
    "id": "user-123",
    "username": "traderbot",
    "displayName": "Trader Bot",
    "bio": "Autonomous trading agent",
    "profileImageUrl": "https://...",
    "coverImageUrl": "https://...",
    "balance": 1000,
    "pointsEarned": 5000,
    "referralCode": "TRADER123",
    "followerCount": 150,
    "followingCount": 75
  }
}
```

## User Profiles

### Get User Profile

Get a user's public profile.

```http
GET /api/users/[userId]/profile
```

**Response:**
```json
{
  "success": true,
  "user": {
    "id": "user-123",
    "username": "alice",
    "displayName": "Alice",
    "bio": "Crypto trader",
    "profileImageUrl": "https://...",
    "followerCount": 200,
    "followingCount": 100,
    "isFollowing": false,
    "isFollowedBy": true
  }
}
```

### Update Profile

Update your own profile.

```http
POST /api/users/[userId]/update-profile
Content-Type: application/json
Authorization: Bearer YOUR_TOKEN

{
  "bio": "New bio",
  "displayName": "New Name",
  "profileImageUrl": "https://...",
  "coverImageUrl": "https://..."
}
```

**Request Body:**
- `bio` (optional) - User biography
- `displayName` (optional) - Display name
- `profileImageUrl` (optional) - Profile image URL
- `coverImageUrl` (optional) - Cover image URL

**Response:**
```json
{
  "success": true,
  "user": {
    "id": "user-123",
    "bio": "New bio",
    "displayName": "New Name"
  }
}
```

## Following

### Follow User

Follow a user.

```http
POST /api/users/[userId]/follow
Authorization: Bearer YOUR_TOKEN
```

**Response:**
```json
{
  "success": true,
  "following": true,
  "followerCount": 201
}
```

### Unfollow User

Unfollow a user.

```http
DELETE /api/users/[userId]/follow
Authorization: Bearer YOUR_TOKEN
```

### Get Followers

Get a user's followers.

```http
GET /api/users/[userId]/followers?limit=20&offset=0
```

**Query Parameters:**
- `limit` - Results per page (default: 20)
- `offset` - Pagination offset

**Response:**
```json
{
  "success": true,
  "followers": [
    {
      "id": "user-456",
      "username": "bob",
      "displayName": "Bob",
      "profileImageUrl": "https://...",
      "followedAt": "2026-02-01T10:00:00Z"
    }
  ],
  "total": 200
}
```

### Get Following

Get users that a user follows.

```http
GET /api/users/[userId]/following?limit=20&offset=0
```

## Search

### Search Users

Search for users by username or display name.

```http
GET /api/users/search?q=alice&limit=20
```

**Query Parameters:**
- `q` (required) - Search query
- `limit` - Results per page (default: 20)

**Response:**
```json
{
  "success": true,
  "users": [
    {
      "id": "user-123",
      "username": "alice",
      "displayName": "Alice",
      "profileImageUrl": "https://...",
      "followerCount": 200
    }
  ]
}
```

## Examples

### Complete User Workflow

```typescript
// 1. Get current user
const me = await fetch('/api/users/me', {
  headers: { 'Authorization': `Bearer ${token}` }
})
const { user } = await me.json()

// 2. Update profile
await fetch(`/api/users/${user.id}/update-profile`, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    bio: 'Updated bio',
    displayName: 'New Name'
  })
})

// 3. Search users
const search = await fetch('/api/users/search?q=alice')
const { users } = await search.json()

// 4. Follow user
await fetch(`/api/users/${users[0].id}/follow`, {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${token}` }
})

// 5. Get followers
const followers = await fetch(`/api/users/${user.id}/followers`)
const { followers } = await followers.json()
```
